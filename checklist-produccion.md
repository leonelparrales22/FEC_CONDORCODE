# Checklist para pasar a producción

- [ ] Habilitación como emisor electrónico en SRI
- [ ] Certificado digital válido (.p12)
- [ ] Pruebas de integración con ambiente de pruebas SRI
- [ ] Validación de XML contra XSD oficial
- [ ] Firma digital con xmlsec1 y validación SRI
- [ ] Configuración de endpoints de producción
- [ ] Auditoría de logs y protección de datos sensibles
- [ ] Empaquetado multiplataforma y pruebas de instalación
- [ ] Cumplimiento de requisitos fiscales y legales
